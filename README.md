# biagui

Aplicacao web criada com Next.js, JavaScript e App Router.

## Requisitos

- Node.js 20.9 ou superior
- npm

## Desenvolvimento local

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no navegador.

As rotas e a interface ficam em `src/app`. O projeto usa JavaScript, sem TypeScript e sem ESLint.
